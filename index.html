01 — Math

Discrete structures & algorithms

We had to compute permutations for a homework assignment, so we wrote the whole thing ourselves — factorial function, distinct-permutation counter, the works. Then we put a browser version on top so you don't need the terminal.

02 — Physics

Interactive simulations

Projectile motion — the classic. You set the angle, the velocity, and gravity, then hit launch. The math runs in real time and you can see max height, range, and flight time update. Checked against the textbook.

03 — Games

Small games, real logic

Guess It is simple — eight random digits between 0 and 9, you guess one number. If it's hiding in the set, you win the round. Sounds easy until you play five rounds in a row and lose most of them. Scores save to localStorage.

About

Built by students, for students

This repo started as our way to learn JavaScript by building instead of just reading tutorials. Everyone picks a page, a tool or a game, builds it, and we review each other's pull requests. That's basically it.
