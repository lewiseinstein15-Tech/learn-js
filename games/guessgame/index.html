Guess It

The computer picks 8 random digits between 0 and 9. You guess one number. If it's hiding in the set, you win the round.

Browser port of the CLI game
rounds 0 wins 0 losses 0

The CLI version kept scores in scores.json and let you play forever in the terminal. The browser port saves scores in localStorage instead. Same odds, same frustration.
