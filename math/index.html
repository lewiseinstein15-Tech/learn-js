Why this exists

Homework turned into code

Our discrete structures class had us computing permutations by hand. It was tedious and we kept making mistakes. So we wrote a script to check our work — and then turned it into a web app. That's basically the theme of this whole project: if something is boring to do by hand, build a tool for it.

The calculator started as a quick exercise but we ended up adding keyboard support, proper operator handling, and a history display. It's not fancy, but it works exactly how you'd expect a calculator to work.
