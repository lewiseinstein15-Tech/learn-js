Calculator

A browser calculator with keyboard support — mostly so we could stop pulling out our phones during group sessions. The logic lives in a single script tag, which we know is not "best practice". It works, though.

live — click or type

note: if you type something like 1+2*3, it evaluates left to right (1+2 then ×3) — we haven't implemented operator precedence yet. it's a calculator, not a compiler.
