    About this app

    This is our first full-stack project. The frontend is vanilla JS talking to a Node.js/Express API. Tasks are stored in a JSON file on the server.

    Right now the backend runs on localhost:5000. We're working on deploying it to Vercel so it works everywhere.

    # to run locally cd mini-projects/todo node server.js

    Without the backend, the app uses localStorage so you can still use it right now.
