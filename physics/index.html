Projectile Motion Simulator

We got tired of memorizing the projectile formulas, so we built the simulation instead. Adjust the sliders, launch, and check whether the numbers in the textbook actually match reality.

live — formulas double-checked against the textbook
max height 0 m

impact velocity 0 m/s

the formulas

• Max height: h = (v₀² sin²θ) / (2g)

• Range: R = (v₀² sin(2θ)) / g

• Flight time: t = (2 v₀ sinθ) / g

Note: the canvas uses a 10 px = 1 m scale, so very long trajectories clip off the edge. We'll fix that with auto-scaling at some point — it's on the list.
