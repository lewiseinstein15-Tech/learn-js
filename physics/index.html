Projectile Motion Simulator

Adjust the sliders, launch, and check whether the numbers in the textbook actually match reality.

Formulas double-checked against the textbook
max height 0 m
range 0 m
flight time 0 s
impact velocity 0 m/s

The formulas

• Max height: h = (v₀² sin²θ) / (2g)

• Range: R = (v₀² sin(2θ)) / g

• Flight time: t = (2 v₀ sinθ) / g

Note: the canvas uses a 10 px = 1 m scale, so very long trajectories clip off the edge. Auto-scaling is on the roadmap.
